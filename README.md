# Notebook Showcase

A minimal client-facing notebook collection site for GitHub Pages.

## Add a collection
1. Put the PDF in `collections/`.
2. Put an optional cover image in `assets/`.
3. Edit `collections` in `app.js` with the title, description, PDF path, and cover path.
4. Push to GitHub and enable GitHub Pages.

The viewer is intentionally simple and uses the browser's built-in PDF renderer, so PDFs stay as PDFs and are not manually converted into individual images.
